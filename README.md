# 数学学习档案

GitHub Pages 发布目录为 docs/。学习数据库、全部题干、逐卷分析及构建所需的原始结构化记录统一保存在 AES-256-GCM 加密的 docs/portal.enc 中；原始试卷继续使用 docs/files/ 中已有的加密档案。口令仅在浏览器解锁时输入，不写入仓库。

拾级包括知识结构、逐卷分析、文字错题集、可编辑、发布的个人练习、A4试卷打印、100题题库及原卷列表。知识点目录与 D3 力导向树采用一致的关注颜色，考试历史使用固定宽度窗口。数据文件与PDF解密后仅在当前浏览器中使用。

本次备份的练习与素材索引也包含在加密档案中；收集的PDF存于 docs/research/，使用同一家庭口令加密。新练习修改加密保存在当前浏览器，仍需导出同步才能跨设备更新。构建源码及版本说明位于 scripts/。D3 的开源许可保存在 docs/vendor/。
